Instrucciones:

  • Usa las flechas del teclado para mover el coche.
  • Usa la tecla shift para activar el turbo.
  • Recoge los bidones de gasolina para aumentar tu combustible.
  • Evita chocar con los cactus.
  • Presiona la tecla "M" para activar/desactivar la música de fondo.
  • Presiona la tecla "I" para mostrar/ocultar las instrucciones.
